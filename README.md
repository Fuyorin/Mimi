\# 🌸 Mimi Discord Bot



A Mimi é uma bot de Discord inteligente com personalidade fofa, carinhosa e natural.



\## 🚀 Funcionalidades

\- \*\*Arquitetura Híbrida\*\*: Groq + OpenRouter para respostas rápidas e sem erros 404/429.

\- \*\*Suporte a MCP (Model Context Protocol)\*\*: Integração com ferramentas locais (filesystem, busca web).

\- \*\*Ações no Chat\*\*: Leitura e resumo de outros canais (`#canal`), visão para fotos/memes e rolagem de dados de RPG (`1d20`).

\- \*\*Respostas VIP\*\*: Tratamento afetuoso e personalizado para utilizadores específicos.



\## 🛠️ Como rodar

1\. Clone o repositório.

2\. Instale as dependências: `npm install`

3\. Crie um ficheiro `.env` com as suas chaves (`DISCORD\_TOKEN`, `GROQ\_API\_KEY`, `OPENROUTER\_API\_KEY`).

4\. Inicie o bot: `node index.js`
